数据说明

  • 名称一列为什么有的是空的？ 有的公示只给"所属网点"或"开取机构名称"，有的干脆只给地址（沈阳、哈尔滨、佛山等离点式清单）。没有名称就留空，用类型＋地址定位，不做臆造。
  • 责任机构为什么大面积为空？ 只有源文件写明维护单位的才填（如河北沧州的揽投部、新疆喀什的分公司）。对云南各地市的表，"所属网点"本身就是该筒箱的维护网点，其名称已经体现在"名称"列，不重复占两栏。
  • 类型与式样：「门前」= 设在邮政营业场所门前（普遍服务标配）；「离点式」= 远离营业场所独立设置的"野生邮筒"。「式样」是子类：立式 / 悬挂式（其下再细分邮筒、邮箱时，类型列写成「邮筒·立式」这样的组合）。新疆喀什的表只分邮筒 / 邮箱、不区分门前与离点式，原样保留。
  • 区域：源文件标注了设置区域（城市 / 乡镇驻地 / 行政村 / 农村 / 景区）的才填，统一写成城区 / 乡镇 / 乡村 / 景区；未标注的留空。
  • 邮编写在地址后面，不单占一列。
  • 坐标只在新疆喀什的 XLSX 附件里有，页面上不展示；结构化 JSON 里保留了经纬度，供导入地图时使用。
  • 芜湖（117 条）是人工转录：源文件为三张表格截图（原始仅 420px 宽），已逐行对图抄录；原文里"江坝坝"这类重复字照原文保留。仍有少量字符受图源清晰度限制，建议与原件比对。
